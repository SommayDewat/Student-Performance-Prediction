# 🎓 Student Performance Prediction System

## 📌 Overview

The Student Performance Prediction System is a Machine Learning project that predicts whether a student is likely to **Pass** or **Fail** based on academic and attendance-related factors.

The model uses historical student data such as study hours, attendance percentage, and previous scores to make predictions and assist in identifying student performance trends.

---

## 🎯 Objective

To build a classification model that predicts student performance using Machine Learning techniques and manage the project using GitHub version control.

---

## 📊 Dataset Features

The dataset contains the following attributes:

| Feature               | Description                    |
| --------------------- | ------------------------------ |
| study_hours           | Number of hours spent studying |
| attendance_percentage | Student attendance percentage  |
| previous_score        | Previous examination score     |
| pass_or_fail          | Target variable (Pass/Fail)    |

---

## 🛠 Technologies Used

* Python
* Pandas
* NumPy

---

## 🤖 Machine Learning Model

**Decision Tree Classifier**

The model is trained to classify whether a student will pass or fail based on the provided academic indicators.

## 🚀 Installation

Clone the repository:

```bash

```

Move into the project directory:

```bash
cd Student-Performance-Prediction
```

Install dependencies:

```bash
pip install -r requirements.txt
```

